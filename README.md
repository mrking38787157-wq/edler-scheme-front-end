# Government Scheme Finder

A responsive, beginner-friendly frontend that helps people explore sample government schemes using their age, state, and selected category. The interface supports English and Kannada and presents possible matches in a clear results list.

## Frontend features

- Age and state selectors
- Selectable Pension, Healthcare, Housing, and Food Support categories
- Sample scheme results filtered by the selected details
- English and Kannada language toggle
- Responsive layout for mobile and desktop
- Accessible labels, keyboard focus styles, and reduced-motion support

## Built with

- HTML for page structure
- CSS for responsive styling
- JavaScript for language switching, category selection, and filtering

## Run locally

Open `index.html` in a web browser. No build tools or dependencies are required.

## Important

This is an educational demo with sample scheme data, not an official eligibility checker. Scheme rules and benefits can change. Confirm current requirements with the relevant government department or official portal before applying.
